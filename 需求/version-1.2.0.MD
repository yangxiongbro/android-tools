# 版本 1.2.0

# 整体要求

- 新增工具「文件同步」

# 工具：文件同步

- 通过 **WiFi / 局域网** 与电脑上的 DevToolbox「文件同步」双向同步：手机上选定一个同步文件夹，电脑上也指定一个文件夹，任意一侧的新增 / 修改都会同步到另一侧
- 支持同时同步到 **多个设备**：电脑端会记住连上来的每一台设备（名称 / IP / 最近同步时间）
- 通过 **蓝牙** 在两台手机之间直接互传文件（先在系统设置里配对）
- 电脑端协议：`POST /sync/hello`、`GET /sync/list`、`GET /sync/download?path=`、`POST /sync/upload?path=&device=`
- 蓝牙协议：RFCOMM（SPP UUID `00001101-0000-1000-8000-00805F9B34FB`），先发一行 JSON 头（文件名 + 字节数），再发文件字节
